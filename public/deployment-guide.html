SHUBHA PATRO (शुभ पात्रो)

Google Cloud Run Deployment & Continuous Update Guide for shubhapatro.com

Application Architecture Reference:
  • Production Domain: https://shubhapatro.com & https://www.shubhapatro.com
  • GCP Project ID: hamropatro-app-live
  • Cloud Run Service: shubhapatro (Region: asia-east1)
  • Container Port: 8080 (Mapped to internal Node server port)

1. The Routine Update Workflow (3 Steps)

Whenever you edit code and want to deploy the latest version to production, follow these 3 simple steps:

Step 1: Push Your Code to GitHub

In your local terminal or editor, commit and push your new changes:

git add . git commit -m "Describe your update here" git push origin main

Step 2: Open Google Cloud Shell & Pull Code

Visit shell.cloud.google.com and run:

cd ~/shubhapatro git pull origin main

Step 3: Deploy to Google Cloud Run (1 Command)

Run the deployment command:

gcloud run deploy shubhapatro \ --source . \ --project hamropatro-app-live \ --region asia-east1 \ --platform managed \ --allow-unauthenticated \ --port 8080 \ --memory 512Mi \ --cpu 1

Google Cloud Build will package your container, run TypeScript build, and deploy a new zero-downtime revision to Cloud Run.

2. One-Click Deploy Script (Alternative)

Inside ~/shubhapatro in Cloud Shell, you can also execute the automated script:

./deploy-gcloud.sh
